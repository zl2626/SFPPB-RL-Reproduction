# SFPPB-RL MATLAB/Simulink 复现

本项目面向 MATLAB/Simulink R2025b。代码组织学习 `AGV_TFS`：被控对象、辅助系统和控制器采用连续 Level-1 MATLAB S-Function，SLX 仅表达清晰的信号流；参数、批量仿真、验收和绘图相互分离。R2025b 的 Level-1 弃用提示属于预期警告。

## AGV_TFS 的代码结构及本项目如何学习

`AGV_TFS` 的核心结构非常小：一个 `AGV_simulate.slx` 表达信号流，`AGV_plant.m`、`AGV_ctrl.m`、`AGV_transfor.m` 和 `assist1.m` 分别承担被控对象、控制器、误差变换和辅助状态，`AGV_RBF.m` 是共享数学工具，`AGV_plot.m` 统一生成全部图。它的优点是“一个物理职责对应一个文件、绘图只有一个入口、模型中能直接看清信号连接”。

本项目学习上述优点，但没有照搬其参数散落、大段废弃注释和重复全局变量。重构后只保留 10 个 `.m`：

| 文件 | 单一职责 |
|---|---|
| `SFPPB_plant.m` | 两个算例的被控对象 |
| `SFPPB_aux.m` | 柔性边界与抗饱和辅助状态 |
| `SFPPB_RL_ctrl.m` | 本文 SFPPB-RL 控制器 |
| `Ref42_SFPPC_ctrl.m` | 文献[42]控制器 |
| `Ref49_ICAS_ctrl.m` | 文献[49]控制器 |
| `sfppb_rbf.m` | 三个控制器共享的 Gaussian RBF 工具 |
| `SFPPB_params.m` | 本文、[42]、[49]的唯一参数入口 |
| `SFPPB_build.m` | 三个 Simulink 模型的唯一构建入口 |
| `SFPPB_run.m` | 全部工况、结果保存和自动验收 |
| `SFPPB_plot.m` | 52 幅主图、对比图和独立面板的唯一绘图入口 |

Plant、Controller、Auxiliary 必须继续分开，因为它们在 Simulink 中代表不同的物理层；把这些 S-Function 强行合并虽然还能减少文件数，但会降低模型可读性。

## 运行顺序

首次创建或需要重建 SLX 时：

1. `SFPPB_build("all")`
2. `SFPPB_run("all")`
3. `SFPPB_plot`

已有 SLX 时可以直接从第2步开始。也可以用 `SFPPB_run("main")` 或 `SFPPB_run("comparison")` 只运行一组工况。运行入口会自动执行验收并更新 MAT 文件。

`SFPPB_plot.m` 只调用 `savefig`。`figures` 目录最终包含 52 个可编辑 `.fig`，不生成 PNG。

绘图采用“结论优先”的定量网格：复合图使用简短标题、统一 `(a)–(d)`
面板标签和非重复图例；Fig.4/9 另带局部放大轴，用于显示被初始权值量级
压缩的细节。普通曲线与局部放大均来自同一个 `main_results.mat`，不使用
平滑、替换或人工生成的数据。

## 公式审查结论

- 本文 SFPPB、非线性映射、Identifier–Critic–Actor 控制律和权值更新律与目标论文公开公式一致；核心控制器中已删除不参与仿真的模型辅助死分支。
- 本文 RBF 中心严格采用论文给出的 `8-(2/3)j`（24 节点）和 `8-(1/2)j`（32 节点），Gaussian 指数中的负号按正确公式恢复。
- 文献[42]控制器严格保留式(24)、(25)、(33)、(39)、(40)。旧版本额外加入的一阶虚拟控制滤波状态已删除。
- 文献[49]采用式(28)--(31)，Identifier 更新律使用 `-kp*Wp+Omega_p*xi`，Critic/Actor 更新包含 `Omega_G*Omega_G'+upsilon*I`，并保留投影算子。
- 文献[49]第一、第二层误差变换均不使用 `0.98` 数值限幅。触及固定边界后由 `valid=0` 记录失效点，运行器保存并截断失效前轨迹。

### Fig.4/9 权值曲线的可复现性边界

目标论文式(43)、(46)只包含秩一半正定项
`S_J*S_J'*W`，没有文献[49]用于消除持续激励要求的 `chi*I`。在论文公开的
24/32节点、宽度2和初值0.4下，当前状态轨迹只能有效激励少量RBF方向，因而
未激活权值保持在初值附近；Critic/Actor范数不能像论文Fig.4/9那样全部降至
`1e-3`量级。Actor与Critic又因相同初值和式(43)、(46)而理论上逐点相同。

因此本项目保留“公开公式忠实模式”，不为匹配图片秘密加入全维泄漏项，也不
伪造权值曲线。Identifier含论文式(40)给出的全维泄漏，其局部量级与论文较为
接近，Fig.4/9的局部放大轴用于如实展示这些变化。若以后获得作者代码，应优先
核对其仿真中是否实际保留了未披露的 `chi*I`。

## 公式审查补充（本轮）

逐条对照论文公式后，本轮修复或确认了两处[42]移植实现：

- 文献[42]式(33)的辅助系统为 `ȯ = -o + (g(u)-u)`，其中
  `g(u)=u_d*tanh(u/u_d)` 是式(3)给出的光滑饱和近似；旧实现误用硬饱和
  `S(u)-u`，已改为 tanh 近似，并与本文 SFPPB_aux.m 的式(24)保持一致。
- 文献[42]式(22)给出 `F1(Z1)=f1(x1)+z2-ẏd+Γ/μ+μz1` 且
  `Z1=[x̄2,yd]^T`，因此第一步模糊基输入应为三维 `[x1,x2,yd]`；
  式(23)中的 `Z1=[x1,yd]^T` 与式(22)矛盾，按式(22)采用三维输入并在代码中注明。

本文方法公式(7)--(15)、(24)、(40)、(43)--(46)与[49]的式(28)--(31)复查未发现
实现偏差；RBF 中心/宽度、误差变换、权值更新律和投影算子均与论文一致。

## 自动验收

- `SFPPB_run("main")`：检查本文四个主工况的边界越界、实际输入限幅和终值误差。
- `SFPPB_run("comparison")`：检查[49]边界内无饱和完成、饱和奇异失效和本文同工况零越界；并记录本文相对[42]的 IAE、原始输入峰值和实际输入绝对积分。
- 详细验收表保存在 `main_validation.mat` 与 `comparison_validation.mat`。

## 公平调参与诊断指标（本轮）

### 同预算公平调参

新增 `SFPPB_tune.m`：proposed/[42]/[49] 各按算例使用 120 次 Sobol 搜索，
统一 4 个标量旋钮、统一目标函数
`J_Q = ∫(z1²+α̂1²)dt + ∫(z2²+u²)dt`，
统一公共工况（`e1(0)=0.05`、无饱和、T=15/20 s）；边界越界、[49] 奇异、
NaN 或权值越界的候选记为 `Inf`。调参结果：

| 本文 Ex2 | 1.910 | γ_c×1.630, γ_a×1.356, υ×1.897, w0=0.103 |

[49] 的无饱和可行工况仍能完成，饱和工况仍按设计奇异失效。

### delta 截断、真实二次代价与秩一激励度

- delta 截断边界集中为 `p.delta_margin`（本文 1e-10，[42] 1e-8），仅作浮点
  安全网；验收表新增 `DeltaClampCount/Fraction/MaxViolation`，本轮全部工况
  截断激活次数为 0。
- `QuadCost` 列为按论文二次代价计算的真值积分；`ExcitedSJ1/SJ2` 列为
  `S_J` 采样矩阵 SVD 的有效方向数（特征值 > 最大特征值 1%）。主方法仅激
  励出 2–3 个方向，定量印证了式(43)/(46) 秩一更新的理论局限；按“忠于论文
  公式”的选择，本轮不引入 χI 或 TD 项。
- 主方法学习率采用调度 `γ(t)=γ0/(1+τt)`（τ 由 N=60 搜索得到：Ex1
  [0.370,0.202,1.898]，Ex2 [1.378,0.933,1.973]），更新方向与论文公式一致；
  公平对比阶段 τ=0 以保证旋钮数量相同。

目标论文未提供原始数据，因此本项目以控制机理、失效现象、指标关系、坐标量级和曲线趋势一致为验收标准，不声称逐采样点完全重合。
